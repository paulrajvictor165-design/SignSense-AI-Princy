📡 REST API Reference

POST/api/detect/objectsObject Detection
Returns detected objects with labels, confidence, position (left/ahead/right), bounding boxes.
Response: {"detections":[{"label":"Person","confidence":0.92,"position":"ahead","bbox":{...}}],"voice_message":"Person ahead."}
POST/api/detect/trafficTraffic
Detects traffic light color via HSV analysis.
Response: {"traffic_light_color":"red","voice_message":"Red signal. Please wait."}
POST/api/ocr/readOCR
EasyOCR text extraction (en, hi) with confidence filtering.
Response: {"text":"Extracted text here...","blocks":[...],"voice_message":"..."}
POST/api/scene/describeGemini AI
Google Gemini 1.5 Flash scene narration for accessibility.
Response: {"description":"You are standing near a road. Two people are walking..."}
POST/api/currency/detectCurrency
Indian Rupee denomination detection via Gemini Vision.
Response: {"denomination":500,"currency":"₹500","voice_message":"This is a Five Hundred Rupee note."}
POST/api/navigation/routeNavigation
Turn-by-turn walking directions via ORS + Nominatim geocoding.
Body: {"start_lat":12.9,"start_lng":77.5,"destination":"Indiranagar"}
