AI Pipeline Improvements · Object Priority · Confidence Scoring · Scene Understanding · OCR Pre-processing

All 5 scope requirements delivered. API is 100% backward compatible — all existing JSON keys preserved, 4 new keys added additively to every response. Flutter requires only the model and camera screen updates (both done in this module).

1. Objective

Implement the enterprise AI pipeline improvements defined in Master Prompt 3, scoped strictly to backend AI logic and the Flutter detection model/camera screen. No architecture refactoring, no HTTP client migration, no navigation changes.

  • Fix the critical safety bug: vehicles announced after chairs due to confidence-only sorting.
  • Add pipeline confidence scoring to every AI service.
  • Add low-confidence retry signalling (backend) and user prompts (Flutter).
  • Improve OCR accuracy with image pre-processing.
  • Improve scene understanding by injecting structured context into Gemini prompts.

6. Confidence Scoring — New Response Fields

Every service response now includes 4 additive fields (existing keys unchanged):

{
  "detections": [...],        // ← unchanged
  "count": 3,                 // ← unchanged
  "voice_message": "...",     // ← unchanged
  "processing_time_ms": 142,  // ← NEW: wall-clock inference time
  "pipeline_confidence": 0.71,// ← NEW: aggregate confidence (0.0–1.0)
  "low_confidence": false,    // ← NEW: true when below tier threshold
  "source_module": "yolo"     // ← NEW: which AI module produced result
}

Per-detection dicts also now include a "priority" integer (1–4).

8. Scene Understanding — Structured Gemini Context

The /api/scene/describe endpoint now accepts optional form fields:

  • detected_objects_json — JSON array of detection dicts from any /api/detect/* call
  • detected_text — OCR text string from /api/ocr/read

When these are present, the Gemini prompt changes from the base template to an enriched template that includes a pre-detected context block, for example:

Pre-detected objects:
  - Car ahead (critical safety risk, confidence 68%)
  - Person on left (navigation hazard, confidence 81%)
  - Chair ahead (environmental object, confidence 91%)

Pre-detected text: "CAUTION WET FLOOR"

Now analyze the image and provide a clear, concise, accessible description...

Old clients that don't send these fields silently fall through to the base prompt — fully backward compatible.

11. Known Limitations

  • Scene enrichment requires the Flutter client to run YOLO + OCR before calling /api/scene/describe and pass the results. This multi-step orchestration is not yet wired in Flutter — it will be addressed when the Flutter architecture module moves screens to ApiClient.
  • OCR pre-processing adds ~30–80 ms per call depending on image size. Acceptable for a static-capture endpoint; not suitable for real-time streaming.
  • Gemini does not return a numeric confidence score. pipeline_confidence for scene is 1.0 when the description is non-empty, 0.0 otherwise — a proxy, not a true model confidence.
  • Currency YOLO model is not configured in the default setup (path is empty). All currency calls go through Gemini Vision until a custom model is trained and configured.
